# Agent Instructions

## Build & Test
| Task | Command |
|------|---------|
| API tests | `dotnet test api\MetaAnime.sln --no-restore` (from repo root) |
| UI build | `cd ui\meta-anime-ui && npm run build` |
| Docker build | `docker build -t meta-anime:local .` |

## Key Conventions
- **C# 14**: primary constructors, `Result<T>` railway pattern for all service returns, no `throw` in service layer
- **Angular 21**: standalone components only, signals (`input()`, `output()`, `signal()`), `@if`/`@for` control flow — no `*ngIf`/`*ngFor`/`@Input`/`@Output`
- **EF Core**: bulk insert for sync jobs; use `AnimeMediatorService` as the high-level coordinator — don't call repositories directly from controllers
- **API key**: dev key in `appsettings.json` is intentional — production key auto-generated by s6 init scripts at first container boot, never commit real keys
- **Error constants**: each operation uses its own dedicated constant from `Constants.Errors`, not a generic fallback

## Project Structure
```
api/MetaAnime.Presentation/    # Controllers, middleware, SignalR hubs
api/MetaAnime.Application/     # Services, Hangfire jobs, business logic
api/MetaAnime.Core/            # Interfaces, domain models, enums
api/MetaAnime.Infrastructure/  # EF Core DbContext, repositories, migrations
ui/meta-anime-ui/src/          # Angular standalone components + services
root/etc/s6-overlay/           # Container init scripts (s6-overlay)
```
